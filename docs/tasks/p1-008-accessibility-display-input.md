## Scope and acceptance

Objective: establish the first truthful accessibility and display/input qualification for the accepted P1 shell. The goal is evidence about the implemented shell, not a claim of full WCAG conformance, screen-reader certification or Windows behavior.

The shell already has accessible names on the toolbar buttons, project tree, function library and preference controls, an offscreen Qt Test suite, window-placement geometry helpers and a shell theme. This task adds missing accessible names/descriptions/roles inspection, records the keyboard focus order, measures text and control contrast in both shell themes, exercises IME composition through the Qt input-method path and through the real macOS Pinyin input method, checks 1x/2x layout and icon scaling, and exercises detach/restore over a simulated display topology. It changes no application/domain contract and introduces no scientific behavior.

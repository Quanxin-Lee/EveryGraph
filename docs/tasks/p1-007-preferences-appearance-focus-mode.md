## Scope and acceptance

Objective: make the P1 shell configurable without mixing user preferences with scientific document state. Interface settings must persist across restarts in a documented local store, invalid values must fall back to documented defaults with diagnostics, and dark appearance must not alter saved publication scene colors or exported backgrounds. The preferences surface, focus modes and panel arrangement must remain keyboard reachable on a small-screen fixture.

This task extends the accepted P1-006 shell. It adds a Qt Widgets preferences dialog, a versioned JSON settings store, shell-only appearance theming, function-library visibility, a default file-format preference, and data-only/commands-only focus modes over the existing docks and document host. It introduces no real project data, no scientific defaults, no persistence of documents and no new module boundary.

Allowed files and interfaces: the `apps/desktop` and `modules/presentation_qt` sources created by P1-006, Qt Test targets and CMake test registration, `docs/engineering/development.md` under the rule 9 designation below, and this record. The P1-004 command kernel remains the only document writer; preference values never reach the kernel and never change the fake project snapshot.

Out of scope: real project persistence, plot/scene color editing, scientific defaults, cloud synchronization, multi-user profiles, OS-level appearance following beyond the stored `system`/`light`/`dark` choice, Windows execution, release packaging and any claim that all preferences or all accessibility behavior is complete. The settings file is a user-configuration store, not a project format, and no migration from a prior EveryGraph settings schema exists because none has shipped.

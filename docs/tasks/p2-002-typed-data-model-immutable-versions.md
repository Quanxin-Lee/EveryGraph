## Scope and acceptance

Objective: implement the in-memory scientific data core that later import, formula, view and persistence tasks consume. The core owns stable object identities, typed columns, immutable dataset versions, row-identity domains, units and provenance edges. It is GUI-independent and does not expose Qt, Arrow object graphs or storage handles in public interfaces.

Allowed files and interfaces: new `modules/data/include/everygraph/data/` and `modules/data/src/` sources, new `modules/data/CMakeLists.txt`, new `tests/data/` tests, the single root `add_subdirectory(modules/data)` registration line required by the P1-011 topology, the `README.md` ADR-index line P0-000 folded into this task, and this record. The command kernel from P1-004 is consumed through its public interfaces. Other modules and documents are read-only.
